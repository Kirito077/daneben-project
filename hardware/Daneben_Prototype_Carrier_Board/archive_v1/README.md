# Archive: Prototype Carrier Board Version 1.0

This directory preserves the historical development files of the initial Carrier Board Version 1.0 (compact 80 mm × 55 mm design).

### Reasons for Supersession by Version 2.0:
1. **Mechanical Clearance:** The compact V1 board lacked sufficient physical clearance for the dual AJ-SR04M waterproof ultrasonic sensor circuit boards and caused mechanical interference when plugging in the shielded transducer probe cables.
2. **Dedicated Power Entry:** Version 1.0 relied on passive power distribution. Version 2.0 incorporates a dedicated onboard USB-C receptacle with 5.1 kΩ CC pull-downs, master slide switch, 100 µF bulk capacitance, and alternate screw terminal.
3. **Variable Container Calibration:** Version 1.0 lacked hardware controls for variable bin heights (from 1m standard wheelie bins up to 4m underground bins). Version 2.0 integrates sizable 12×12 mm dual pushbuttons with status LEDs for one-click field calibration.
