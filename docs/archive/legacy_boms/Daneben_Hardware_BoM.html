SECTION 5: HARDWARE RECEIVING & VERIFICATION PROTOCOL

  • ESP32-S3 Sense Inspection: Connect to PC via USB-C. Open serial terminal @ 115200 baud. Verify boot log prints: Total PSRAM: 8388608 bytes (8MB). If PSRAM reports 0 or 2MB, board is defective or incorrect model.
  • Camera Flex Seating: Inspect OV2640 ribbon insertion. Run CameraWebServer example to confirm clean 1600×1200 frame capture before enclosure mounting.
  • Ultrasonic Echo Timing: Probe Trigger/Echo lines on oscilloscope or Arduino sketch; verify stable 58 μs/cm return pulses without jitter.
  • Speaker Polarity: Ensure positive/negative speaker leads are soldered firmly without hair shorts to the Class-D filter chokes.
